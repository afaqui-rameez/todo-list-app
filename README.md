# To-Do List App

A simple and interactive To-Do List application built with React to help users manage daily tasks efficiently.

## 🚀 Features

* Add new tasks
* Display tasks in a list
* Manage tasks using reusable React components
* Clean and simple user interface
* Component-based architecture

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Vite
* npm

### Prerequisites

* Node.js
* npm
* Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/afaqui-rameez/todo-list-app.git
   ```

2. Navigate to the project folder:

   ```bash
   cd todo-list-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
